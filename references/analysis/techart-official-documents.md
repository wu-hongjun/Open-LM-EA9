# Official Techart document notes

Research date: October 10, 2026. Direct file downloads returned HTTP 403, while
the web research service could read both sources. These are concise paraphrased
notes; the original PDF and page HTML were not archived locally.

## LM-EA9 product page

[Source](https://techartpro.com/?product=lmea9).

Techart describes four radially arranged motors, 4.5 mm extension, USB updates,
phase-detection autofocus driven by the Sony camera, and camera stabilization
using focal-length information. It supports stacking adapters for other manual
lens mounts. This manufacturer's physical motor count should be reconciled with
the EA9 source's coordinated PWM outputs before inferring internal wiring.

## LM-EA9 user manual

[Source](https://techartpro.com/wp-content/uploads/2023/01/User-Manual-LM-EA9.pdf).

The update workflow connects USB to the dock in the adapter's rear cap and
selects a firmware version in the updater. The manual describes using camera
aperture settings and a shutter release to store adapter settings, then returning
the camera setting to f/2. It identifies f/45 for parking behavior, f/51 for normal
focus, and f/57 for slower focus with fast lenses. Physical working aperture is
set on the lens separately. The focal-length example mentions f/32 for 400 mm;
the extracted text does not contain a complete focal-length mapping table.
