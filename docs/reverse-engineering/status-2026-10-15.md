# Factory reconstruction status — October 15, 2026

We have recovered useful factory contracts and an executable host model of
selected behavior. We have **not** reconstructed a complete factory-equivalent
firmware, and no new upstream C candidate has established factory parity on the
A7C II. A buildable replacement and a complete reconstruction are different
milestones. The [timed hardening ledger](../firmware-hardening-2026-10-15.md)
identifies release evidence and the separate
[3.6 installation/reconnect gate](../evidence/upstream-36-upload-2026-10-15.md).

| Area | Evidence established | Remaining limit |
| --- | --- | --- |
| Image layout and preservation | Original application retained exactly; 235 instruction-bearing app functions inventoried; flash partitions and duplicate application identified | A complete inventory is not semantic equivalence; purpose of all retained copy/header bytes is unresolved |
| Factory AF arithmetic and callback | Original-instruction comparison covers target narrowing, speed staircase, incremental PID, completion/Stop and timer divider/timeout; 7,323 pure-controller cases with a detected gain mutation | Driver registers are partly stubbed; finite states do not establish physical control or whole-app scheduling |
| Application orchestration and sensor/origin | Original 38-entry host suite plus three sensor/origin routines: 41 semantic-model routine entries; the extension includes 68,648 instruction cases/steps and a detected byte-order mutation | The modeled union is not all 235 app routines; physical reference, calibration and all callers remain incompletely qualified |
| Frame and lifecycle contracts | Recovered dispatch/sequence/raw capture/shutdown behavior informs explicit source invariants and interruption tests | Our ownership snapshots, terminal faults and no-new-park policy deliberately differ from factory behavior; they require camera qualification |
| Boot/update and persistent state | Original bytes, updater behavior, settings schema and guarded upload/restoration; audit 24 executes original reset-to-app path and establishes conditional CONTROL/PRIMASK/priority preservation, NVM IRQ5 enable and boot SysTick state | Physical exception handoff, arbitrary inherited/active state, complete bootloader recovery and all persisted field semantics remain open |
| Terminal shutdown tail | Audit 31 executes original formatter, interrupt-mask helpers, UART disable and sleep setup in 35 supplied-state cases; nine incorrect interpretations rejected | WFI is a stop-before boundary or explicitly supplied wake; no physical sleep, wake, motor arrival or whole-program reachability proof |
| E-mount public captures | Archived captures ground frame structure and some field layouts; workload audit finds no query records in the inspected body 0x04 traffic | No real 0x22/0x2e batch rate or camera response deadline is established; synthetic queue tests are not captured workload |
| A7C II and Contax 50mm behavior | Owner observations and strict upload records distinguish historical failures, stock comparison and an initial metadata photograph | Actual optical AF, exposure, capture and shutdown acceptance for later offline candidates remain unverified |

The active upstream C controller is **not the recovered factory PID**. Earlier
AF 2.4–3.0 experiments used the factory-derived module and exposed wrapper/camera
failures. The current work builds on the pinned upstream implementation, using
REA/original-instruction findings to check contracts and fix reproduced source
faults. Shared-sample target handoff, for example, is supported by the recovered
absolute-target contract without transplanting factory gains or saved origin.

The next useful factory work should close a specific missing contract with
original-instruction evidence and a failing control, then compare it with the
actual production caller. Do not import all reconstructed behavior simply because
its pure math passes. Mechanical calibration, real traffic timing and matched
camera trials need owner-coordinated hardware evidence. No source simulation can
supply those observations.

count. The [startup handoff review](../audits/astra-28-startup-handoff-review-2026-10-15.md)
supports a scoped ownership fix in upstream C 3.6; it does not establish complete
peripheral scheduling equivalence or explain the prior camera freezes.

The [terminal-tail audit](../audits/astra-31-factory-shutdown-tail-2026-10-15.md)
corrects an older oracle boundary: `0x51c8` observes the request before formatting,
while original instructions normalize checksum/terminator before UART `0x9180`.
State2 does not recheck completion; inherited PRIMASK and supplied peripheral
inputs affect progress. These are bounded instruction contracts, not another
independent C model or an increase to the 41-entry semantic-model union. Exact
3.6 source review identifies no justified runtime change from this finding.
