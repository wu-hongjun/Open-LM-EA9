# Native UI simplification

The owner's requested layout is two cards: **Adapter on the left, Lens on the
right**. Device remains the home tab; Lens Library is secondary.

The Adapter card keeps the product photo, connection status, firmware/version
verification date and one USB tools button. The Lens card keeps its photo,
compiled profile, Sony aperture range, unknown physical aperture and Library
link. Reconnect/error/progress guidance appears only when relevant.

Removed: hero slogans, duplicate firmware card, decorative category headings,
local-only profile selection from Device, repeated captions, retired firmware
install buttons and empty manual-setting sections. Library cards open their
editor directly. Firmware updates and stock recovery sit inside the USB panel.
No operation is automatic beyond descriptor discovery and local-history refresh.

The native two-card and library layouts were inspected in an isolated preview
with USB actions disabled, including the wider range displayed separately from
the Biotar's nominal f/2. The preview uses a separate bundle identity and
temporary state; it does not present mocked values as a real adapter read.
Unit tests cover preview inhibition, discovery, local selection/history,
corruption, active-image admission and rollback.

## Claude Code review

The [source audit](audits/claude-ui-2026-11-07.md) completed using Claude Code
foreground print mode with all tools disabled and an empty strict MCP config.
Only five supplied UI source files were sent; no device/runtime data was used.
The background dispatcher failed to launch, so it was not used for the review.

Verified findings were integrated: distinguish a version read from full image
verification, hide casual upload cancellation, keep progress above the fold,
state the backup requirement, mark installed firmware and hide its install
button, remove duplicated Library/review controls and captions, and simplify
empty states. Compiled lens labels now share the image setting source. Native
segmented navigation and semantic colours replace custom tabs/fixed light mode.
Cards use a smaller radius. Firmware updates and Recovery use matching disclosures.

Two review assumptions were checked rather than copied: newer conflicting
observations already hide stale applied-lens data; this guard is retained and
regression-tested. The `55` in the Biotar's legacy library ID is intentionally
stable; its name and focal metadata correctly say 58mm, so the ID is not renamed.
Upload cancellation also already had a warning; the everyday cancel button is
now restricted to reads while the explicit quit safeguards remain.

The named native tests now total 49. Physical camera observations remain the
owner's 4.5 report; 4.6 is still offline-only. Light and dark preview state is
isolated from real app state, with every USB action disabled.
